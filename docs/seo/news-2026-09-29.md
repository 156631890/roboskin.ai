## 1. Uni-VLaT

- Paper: `arXiv:2609.35450v1`
- First public event: 2026-09-28 15:43:26 UTC
- Primary sources: [arXiv record](https://arxiv.org/abs/2609.35450), [full v1 HTML](https://arxiv.org/html/2609.35450v1), [official project](https://ggkiller-air.github.io/Uni-VLaT/)
- Article: `/news/univlat-whole-body-tactile-vla-humanoid`
- Search intent: understand how whole-body tactile sensing changes humanoid VLA policy performance and what is publicly available.
- Fact checks: eight skin regions; about 50 demonstrations per task; main Isaac-GR00T comparison uses 20 rollouts per configuration; reported average success is 32% without touch, 68% with touch/no prediction, 69% with tactile-only prediction and 75% for the full model. The separate pi-0.5 transfer comparison uses 10 rollouts per configuration. Electronic-skin readings are pressure-related ADC values in arbitrary units.
- Availability: project videos are visible. The project page still labels code as coming soon; no code, dataset, checkpoints or release license were verified.

## 2. Unified Visual-Tactile-Action learning (UVTA)

- Paper: `arXiv:2609.34182v1`
- First public event: 2026-09-28 02:59:16 UTC
- Primary sources: [arXiv record](https://arxiv.org/abs/2609.34182), [full v1 HTML](https://arxiv.org/html/2609.34182v1), [official project](https://uni-vta.github.io/)
- Article: `/news/uvta-human-tactile-demonstrations-dexterous-manipulation`
- Search intent: inspect UVTA's human tactile demonstration dataset, evaluation metric and release status.
- Fact checks: five tasks contain 1,000 human plus 150 robot demonstrations each, or 5,750 trajectories total; the recorded streams include 20-dimensional touch and 31-dimensional actions at 30 Hz. Physical evaluation uses 10 trials per task and reports stage-weighted completion, not strictly binary trial success. The reported average is 70%, compared with 29% for T-Rex, 14% for RDP and 1% for ViTacFormer under the paper's protocol.
- Availability: the project links a GitHub repository, but the public endpoint returned 404 when checked. No downloadable dataset, code or release license was verified.

## 3. TacGooseBumps

- Paper: `arXiv:2609.34006v1`
- First public event: 2026-09-27 23:04:32 UTC
- Primary sources: [arXiv record](https://arxiv.org/abs/2609.34006), [full v1 HTML](https://arxiv.org/html/2609.34006v1)
- Article: `/news/tacgoosebumps-shear-encoding-tactile-sensor`
- Search intent: understand how a passive film can add shear-sensitive patterns to a pressure array and what the robot experiments actually measure.
- Fact checks: the interface changes the mechanical layer without adding sensing electronics and does not provide calibrated shear vectors. The USB task reports 19/20 and 18/20 for two TacGooseBumps interfaces versus 15/20 bare; the bulb test reports 24/25 versus 15/25; both egg policies completed 25/25 binary trials, but two eggs cracked without the interface. External cup load is a proxy, with reported peak reduction from 0.77 to 0.26 in the paper's units.
- Availability: no official project, code, CAD, data, checkpoints or software license was verified.

## 4. DexTaG

- Paper: `arXiv:2609.33882v1`
- First public event: 2026-09-27 19:56:41 UTC
- Primary sources: [arXiv record](https://arxiv.org/abs/2609.33882), [full v1 HTML](https://arxiv.org/html/2609.33882v1), [official project](https://dextag.github.io/), [official repository](https://github.com/UMass-Embodied-AGI/DexTaG)
- Article: `/news/dextag-tactile-guided-dexterous-retargeting`
- Search intent: assess DexTaG's tactile-guided retargeting method, baseline conditions and actual open-source release.
- Fact checks: source demonstrations comprise 100 pen and 140 hammer trajectories; the tactile glove is represented as a 24 by 32 map and transferred to about 700 simulated contact points. Five-seed ablations report 87.5% ± 4.0% and 76.8% ± 27.7% mean reward for pen and hammer. The OakInk2 comparison does not match compute: DexTaG reports 24 policy-training hours per trajectory versus eight for ManipTrans/WUJI, although its aggregate policy-training total is lower because it trains three policies rather than one per trajectory.
- Availability: the MIT-licensed repository contains code, a roughly 209 MB demonstration archive, two retargeter files and setup/train/evaluate instructions. Real-robot control code and student checkpoints were not explicitly verified.
