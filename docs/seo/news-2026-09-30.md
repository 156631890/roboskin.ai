## Article evidence

### 1. TaRL

- Paper: `arXiv:2609.36785v1`, submitted 2026-09-29 05:56:43 UTC.
- Primary sources: [arXiv record](https://arxiv.org/abs/2609.36785), [full v1 paper](https://arxiv.org/html/2609.36785v1), [official project page](https://embodiedai-ntu.github.io/tarl/).
- Search intent: understand how tactile demonstrations can supervise robot rewards, what data is required and how the real-world claim is bounded.
- Key checks: 200 successful plus 800 failed simulation demonstrations per task; 40 plus 40 physical reward demonstrations; separate 90 plus 90 offline-policy trajectories; 34% to 56% simulated nut threading; 37% to 97% physical cube pickup; three training seeds.
- Verification increment: the paper does not disclose the number of physical inference trials per seed, so the 60-point gain is not presented with an invented denominator or confidence interval.
- Availability: the project exposes explanations, plots and videos. No public code, demonstration archive, trained reward model or implementation license was verified.

### 2. HACo

- Paper: `arXiv:2609.36596v1`, submitted 2026-09-29 03:17:04 UTC.
- Primary sources: [arXiv record](https://arxiv.org/abs/2609.36596), [full v1 paper](https://arxiv.org/html/2609.36596v1), [official project page](https://opendrivelab.github.io/Haco-Page/).
- Search intent: assess whether fingertip touch plus joint torque and compliant demonstrations improve force-sensitive dexterity.
- Key checks: five physical tasks; 20 trials per task-method pair; 83/100 HACo successes; 35/100 for T-Rex; 100 task-specific demonstrations per task; ten fingertip tokens and 44 joint-torque measurements.
- Verification increment: the 48-point gap is a system-level comparison across models with different pretraining and architecture. Within-HACo ablations provide the cleaner component evidence.
- Availability: project videos, counts and failure cases are public. Code is explicitly labelled “Coming soon”; no dataset, checkpoints or implementation license was verified.

### 3. Single-element pressure and tackiness sensor

- Paper: `arXiv:2609.36558v1`, submitted 2026-09-29 02:42:32 UTC.
- Primary sources: [arXiv record](https://arxiv.org/abs/2609.36558), [full v1 PDF](https://arxiv.org/pdf/2609.36558). The experimental arXiv HTML endpoint returned 404 during verification and was not published as a reader link.
- Search intent: understand how one Hall element distinguishes compression from adhesive pull-off and what was physically validated.
- Key checks: reported 0–150 kPa pressure range and 0–33 kPa pull-off range; pressure response/recovery of 33.2/33.5 ms; pull-off response/recovery of 21.8/10.3 ms; ten-hour baseline test; more than 50,000 pressure cycles near 63 kPa; 5,000 pull-off trials.
- Verification increment: response tests, normal characterization and robot demonstrations use different supply voltages; the sensor is one element, not an array; pull-off peak alone can mis-rank tackiness at slow separation speed.
- Availability: no official project, CAD, fabrication repository, raw dataset or implementation license was identified.

### 4. Wrench-ACT

- Paper: `arXiv:2609.37552v1`, submitted 2026-09-29 13:29:06 UTC.
- Primary sources: [arXiv record](https://arxiv.org/abs/2609.37552), [full v1 paper](https://arxiv.org/html/2609.37552v1).
- Search intent: determine when direct six-axis wrench actions outperform position actions and whether the promised wrench dataset is available.
- Key checks: four collection/action conditions; five tasks; 50 rollouts per task-policy pair, or 1,000 main evaluation rollouts; 76.8% mean for bilateral-wrench versus 40% for VR-position; statistically significant differences on three tasks after correction; 50 Hz policy and 500 Hz controller loops.
- Verification increment: the average hides an 88% versus 96% loss on fuse clipping and a non-significant pen-writing difference. Wrench output alone reaches only 28.8% when trained on wrenches reconstructed from ordinary VR position data.
- Availability: the manuscript promises more than 1,000 wrench-action demonstrations on a companion site upon publication. No companion URL, archive, repository or release license was verified with v1.
