# Tactile evidence-chain review — November 4, 2026

Scope: six existing research-news reports and `/tactile-ai`. Original publication dates, useful modules, anchors, images and links are retained. This is source review and editorial interpretation, not hardware testing, data-payload verification or human factual sign-off. The whole-site goal remains active.

## Primary-source work

Read all six original full papers, including relevant method, experiment and appendix sections. TouchWorld uses the July 9 v2 full text; the other five use v1. Current metadata, source URLs, HTTP responses and content hashes are retained in the local batch80 source records. Read current official project pages, README and license text as applicable; no project was installed or executed and no research dataset was downloaded.

- RADMCS: https://arxiv.org/html/2610.01906v1. Threshold study subsets differ from the seven-person pool navigation study. Manufacturer thrust curves are not calibrated body-contact force. Safety-diver assistance and the one-person ocean fit test are separate evidence. New review table concerns observation validity, human response and supervision, not an operating procedure.
- CableVLA: https://arxiv.org/html/2609.25606v1. Gate checks any valid threshold crossing in the 25-frame history, rather than only current contact. Eight actions are committed before replanning; 30 Hz observation does not imply a model query per command. Zero-shot weights still coexist with calibration and lighting preparation. Preserve the simulation and ten-trial hardware denominators.
- Tactile-JEPA: https://arxiv.org/html/2609.24385v1. Known adjacency is required; numerical 3D coordinates are not. Separate per-dataset/task encoders, short input windows, downstream heads and split units. Eight blocks for socks, twelve for Xela/DECO. Original DECO action RMSE is not physical success. Repository `E-Kovtun/tactile` at `ffb4db04080d98ff6b61dad04ba0bc0a49f8bd28` now documents a separate follow-up recipe and head-level spread; retain original paper results rather than silently replacing them. README pretrained-model field is TBD. Root CC BY-NC 4.0 does not govern all third-party assets.
- CRISP: https://arxiv.org/html/2609.21761v1. Appendix D's underdetermined contact distributions separate stable motion from calibrated local pressure. Preserve peg versus bolt metric definitions, convergence/failure cases and historical package evidence. Current `INRoL/crisp` revision `3d47426cac6f001b16f8d613339383c144029e88` still documents prebuilt-package examples and restrictive academic/noncommercial terms; no full-engine source or hardware validation claim.
- TWINS: https://arxiv.org/html/2608.01733v1. Assistant contact cues and object presentation are part of the protocol. Padding on both object and chest changes mechanics. Forty demonstrations, 219 cells/438 values and 10 Hz recording are different units; qualitative task execution lacks a success denominator and matched tactile ablation. Hardware revision `fe9b8090edd8601798dbc618e1d9a9711a8c9697`, CERN-OHL-W-2.0. Official project still labels learning code forthcoming.
- TouchWorld: https://arxiv.org/html/2607.07287v2 and https://phanes-lab.github.io/TouchWorld-website/. Six task rows and clean/perturbation means reproduced as author reports, not a universal ranking. The 100-rollout statement does not clearly allocate conditions. Goal prediction is not an arbitrary-action counterfactual interface. Cached goals, H32 nominal actions, W16 residual context and four committed actions do not establish Hz/latency. Correction covers a 58-dimensional subspace. Human pretraining applies to predictive module with robot-specific training. TouchAnything `d74f9ef5c189a957b7ff72781a0c998e41b45a56` is a separate code project; README upload warning and MIT code license do not establish complete EgoTouch payloads or TouchWorld checkpoint rights.
