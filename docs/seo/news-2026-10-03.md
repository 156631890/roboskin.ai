## Article evidence

### 1. Reactive Humanoid Multi-Contact

- Paper: `arXiv:2610.00823v1`, submitted 2026-09-30 23:33:29 UTC.
- Primary sources: [arXiv record](https://arxiv.org/abs/2610.00823), [full v1 paper](https://arxiv.org/html/2610.00823v1).
- Search intent: understand how a humanoid can select a useful hand brace before foot-only push recovery fails.
- Key checks: simulated impulses 15.6/17.7/23.0 N·s without bracing, 25.8/36.4/26.6 N·s with the nearest brace and 29.4/42.3/32.1 N·s with optimized contact; learned path 9.7 ms versus numerical 388 ms; 10 + 10 standing pushes and 12 walking pushes.
- Verification increment: recomputed the mean relative gains as 89.0% versus no brace and 16.9% versus naive bracing; reconstructed the 43% headline standing reduction from the two reported 57% and 29% protocols; retained that hardware push magnitude was proxied, not directly measured.
- Availability: manuscript public under CC BY 4.0. No official project, code, dataset, model weights or software license verified.

### 2. Continual 6-DoF Grasp Synthesis

- Paper: `arXiv:2610.01301v1`, submitted 2026-10-01 08:36:06 UTC; accepted to CoRL 2026.
- Primary sources: [arXiv record](https://arxiv.org/abs/2610.01301), [full v1 paper](https://arxiv.org/html/2610.01301v1), [official project](https://giuschio.github.io/cl_grasping/).
- Search intent: determine how deployment outcomes and occasional demonstrations can improve 6-DoF grasping without updating network weights.
- Key checks: 443 unseen simulation objects, 2,500 attempts per category and method; 54 physical objects and more than 1,500 physical attempts; 20 fixed evaluation scenes per physical category; at most 50 adaptation attempts per category; five of six physical groups exceed 90% after adaptation.
- Verification increment: preserved the nonuniform number of physical attempts caused by scene clearing; separated score-memory gains from proposal-recall gains; retained the 62.5% to 68.3% pliers limitation rather than generalizing the five stronger categories.
- Availability: official videos public; code labeled coming soon. No repository, trained model, memory archive, physical dataset or implementation license verified.

### 3. Jacobian Flow Matching for a Rigid-Soft Finger

- Paper: `arXiv:2610.01668v1`, submitted 2026-10-01 13:29:03 UTC; under review at Robotics and Autonomous Systems.
- Primary sources: [arXiv record](https://arxiv.org/abs/2610.01668), [full v1 paper](https://arxiv.org/html/2610.01668v1).
- Search intent: assess whether a learned Jacobian can stay consistent when a soft finger's sensing or control interval changes.
- Key checks: about 10,000 samples; pose at 45 Hz and servo state at 55 Hz; TinyTransformer and LSTM average RMSE reductions of 57.27% and 53.68%; 160 held-out trajectories; stride-8 median RMSE reduction 14.43% and variance reduction 24.87%; pointwise query about 3.5 ms.
- Verification increment: distinguished prediction RMSE from task success, reported both backbones, and kept open-loop inverse validation separate from an unperformed closed-loop ODE controller demonstration.
- Availability: ROS 2-to-HDF5 pipeline described, but no public data, code, checkpoint, CAD or implementation license verified.

### 4. SkeleWAM

- Paper: `arXiv:2610.02120v1`, submitted 2026-10-01 17:35:10 UTC.
- Primary sources: [arXiv record](https://arxiv.org/abs/2610.02120), [full v1 paper](https://arxiv.org/html/2610.02120v1), [official project](https://skelewam-project.github.io/).
- Search intent: determine whether sparse robot-object geometry can replace pixel or visual-latent future targets in a world action model.
- Key checks: 10,030 LIBERO-Plus variants; 57.1M parameters; 85.9% overall versus 82.2% Cosmos-Policy; 66.6% layout result versus 84.1% π0.5; five physical tasks with 20 trials each; 89/100 total physical successes.
- Verification increment: summed physical trials explicitly, treated the two-success margin over Cosmos-Policy as small, and used the privileged sim-state result to show layout weakness is not only a perception error.
- Availability: project tables and recorded demos public. No repository, checkpoint, dataset, perception package or implementation license verified.
