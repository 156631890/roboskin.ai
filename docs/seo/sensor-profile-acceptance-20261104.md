## Primary evidence read

- Robotiq user guide v1.0.0: https://robotiq.com/hubfs/Tactile%20Sensor%20Fingertips/Tactile%20Sensors%20TSF-85%20-%20User%20Guide.pdf . Read compatibility, intended use, specs, integration and maintenance. Pressure is raw CDC counts; per-taxel bias/gain and nonlinearity discussed in 4.1; 60 Hz array versus 1000 Hz dynamic/transport; high-frequency gripper control not provided by the fingertip. Two fingertips required; starter/replacement kit contents differ. Do not transplant the uniform-load scaling example onto arbitrary point contacts. Numeric pressure resolution/noise table formatting is ambiguous, so no new numeric force-resolution claim.
- Robotiq July 8 design article: https://blog.robotiq.com/how-robotiq-built-the-tsf-85-tactile-sensor-to-the-spec-of-the-human-hand . Manufacturer's calibration and durability reporting is not our independent measurement. Preserve the existing dated SDK pin rather than imply it was executed.
- Original DIGIT paper https://arxiv.org/pdf/2005.14679 , especially Table I and III.D: the controlled abrasion comparison uses a particular tip/load and optical-transmission change; one comparison gel was not designed for robotics. This is not evidence against all current GelSight products. Official https://digit.ml/digit.html confirms image-output, interface/design and simulation routes; purchase is separate from repository reuse. Existing archived-repository and licensing observations retain their original September review date.
- GelSight Mini datasheet https://www.gelsight.com/wp-content/uploads/productsheet/Mini/GelSight_Datasheet_GSMini.pdf . All three pages read. Page 3 specifies camera/FOV/environment and a thermal test under its stated conditions, not a universal calibration warm-up duration. Its 1000 coin presses are a named test, not a field lifetime rating. https://www.gelsightmini.com/ public shell readable. Pinned gsrobotics GitHub web read returned restricted URL; no bypass, execution or new claim of repository verification. Prior source-dated README values remain historical. Search returned a proxy mirror; excluded from evidence.
- ReSkin paper https://arxiv.org/pdf/2111.00071 (v2, February 12, 2022), sections 3–7; https://reskin.dev/ official project. Section 5's 50K samples / random 45K–5K split differs from chronological experiments. Section 6 holds out a board with three skins among 18 skins / six boards; adaptation uses new-skin observations. Do not call adaptation data-free or equate localization accuracy with force error. Project links code and a model, but no data/model payload, fabrication or hardware test was performed.
