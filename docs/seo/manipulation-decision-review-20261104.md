## Blind Grasp Reflex

Primary: https://arxiv.org/html/2609.31323v1 ; https://blindgraspreflex.github.io/ . Full methods/results reviewed from saved source. September 25 v1. Inputs are joint-position history and measured-minus-low-level-command tracking error, not necessarily raw policy targets. Velocity-limited command generation and gains affect the proxy. Teacher uses privileged contact/object state; student does not have touch arrays. Hand policy 11.9 Hz, arm 200 Hz and low-level 1 kHz are different loops. Grasp score drives a hysteretic reversible FSM, not a calibrated safety probability.

Correct the 95% claim: Table II allows retries in a 30-second window, requiring a 2-second hold within 10 cm of the target. YCB 96% and GraspXL 95% are window outcomes; per-attempt result is 85%, same as the privileged baseline. Dynamic 92% uses ten approximately spherical YCB objects within the trained workspace; it is not an unrestricted dexterous benchmark. Correlation 0.77 is averaged within-episode Spearman over 15,097 episodes, not pooled calibration. Hardware 29-object examples lack a repeated-trial denominator. Cross-arm transfer is not cross-hand transfer. Halving command velocity changes performance substantially, establishing controller dependence. Current project source must be checked for actual implementation links; do not promote old Coming Soon language as current proof of absence.

## DA-GRD

Primary: https://arxiv.org/html/2609.29065v1 . Full paper reviewed. September 24 v1. An initial grasp is executed first; zero additional probes still includes that physical contact. The 256-particle SE(2) belief and free-space/surface evidence do not model arbitrary 3-D rotations or disturbance. Probe scoring uses a counterfactual miss plus surface novelty and motion/repeat costs, not a full expected-value calculation over hit and miss outcomes. Geometric posterior grasp coverage is not an empirically calibrated success probability.

100 shared perturbations per ten objects produce 1,000 simulation episodes. Translation is up to 50 mm per axis, not a radial 5 cm envelope. Lift 84.7% versus 63.7% and task 57.3% versus 49.2% are distinct criteria. The 4.13 probes is the macro-average of per-object means on lift-success episodes, including initial zero-probe successes; not all-attempt time savings. Baselines differ in refinement, probe selection and stopping. Hardware six objects with ten trials each yields 71.7% lift and 38.3% task; do not merge their denominators or call probe count wall-clock efficiency. Two lateral FSRs and a wrist F/T sensor mean it is not sensorless. No separate implementation release verified.

## Better Curriculum

Primary: https://arxiv.org/html/2609.25887v1 and author project. Full paper/appendices reviewed. September 22 v1; project labels CoRL 2026. A single operator sees tactile GUI in both manual and reflex collection. Follower realized 7-D trajectories are logged, not simply raw leader commands. Curriculum refers to demonstration-distribution shaping rather than a staged training scheduler. Tactile-free learned policies still use RGB/proprioception; optional runtime tactile arbiter owns gripper behavior, not whole-arm safety. Capture 25 Hz, ACT 15 Hz and pi0.5 actions 20 Hz/chunk query about 1.7–1.8 Hz are separate clocks; camera freshness is not fixed by nominal frame rate.

Thirty curated manual trajectories out of 100 are not a 30% collection-success rate. Data collection order was not randomized. Main-seed ACT 19/20 versus 3/20 and pi0.5 19/20 versus 1/20 compare collection regimes; adding a runtime arbiter to manual-data policies yields 10/20 and 11/20, so it does not replace better examples. Main-seed disturbance 20/20 is not a failure-proof guarantee: four additional seeds total 79/80 with arbiter versus 42/80 without. Quality/force proxies are not calibrated newtons. In-band frame occupancy is duration-conditioned, not whole-trial task success; the manual occupancy reference comes from a single eight-frame episode. General author GitHub profile is not a verified dedicated implementation release.

## TacEx

Primary current v3: https://arxiv.org/html/2609.40134v3 (October 13); original September 30 v1 retained as history. Project https://go.klem.nz/tacex redirects to https://kiten.me/projects/tacex/ and now links https://github.com/klemensiten/tacex . Current README/root API read successfully. Repository is public, contains two experimental pipelines and upstream submodules; GitHub license metadata is null and root LICENSE request 404. That does not prove no permission exists anywhere: no applicable project-wide license was verified in the reviewed root/README. Do not inherit upstream licenses or claim execution/checkpoints/data verified.

Full v3 including appendices reviewed. Correct affiliation to ETH Zurich and UC Berkeley, not UT Austin (conference location). All experiments simulated. Reward-free collection uses intrinsic disagreement with zero extrinsic reward; frozen buffer is later reward-relabeled and trained offline. Diffusion steering is a separate online task-reward experiment with a learned noise policy around a frozen VLA. Base VLA receives its original visual/proprioceptive/language inputs; steering learner/critics receive touch. Bonus weights do not determine all policy observations. Reward-free plots use five seeds and last-ten-checkpoint averages; steering ten seeds. Figure 6 final return is time-weighted over the final 10% of training, distinct from full-horizon normalized AUC. Effective object count 2^H is an interaction-distribution entropy statistic, not number of tasks solved. Mixed visual/tactile bonuses can improve diversity; no universal tactile-only winner. Force maps are simulated spatial normal/shear vectors; optical tactile replacement is proposed, not evaluated. Noise, drift, wear and safe forces untested. README max_steps counts gradient updates for replay steering; environment steps logged separately. Do not convert config counts into physical trials or elapsed time.

## GLoTouch

Primary: https://arxiv.org/html/2609.27695v1 . Full paper reviewed. September 23 v1. Camera-free external scene exploration still uses optical fingertip sensors, proprioception, wrist F/T, known STL models, container registration, known cardinality and top-accessible objects. Rigid probe has known support geometry but no embedded sensor; wrist F/T detects contact. The 0.37 mm calibration-center result is one square geometry, not general 3-D localization accuracy.

Local matching uses reconstructed tactile depth and gripper aperture, not RGB channels; nuisance scale/yaw/aperture bias are handled in a finite-window fit. Decisions require sufficient evidence, absolute quality and best/second margin, not unconditional argmin. Development matcher 54/60 on five objects is not unseen-object performance. Loss margins from differently scaled objectives are not directly comparable. End-to-end physical 38/50 (five targets, ten each), simulation 84/100 (includes runtime failures) and complete five-object search 55%/100 episodes versus random 30% are separate outcomes. Object motion can stale the contact map; unknown classes and arbitrary clutter are not established. No separate release manifest verified.

## PHASE

Primary: https://arxiv.org/html/2609.30889v1 and https://omron-sinicx.github.io/phase/ . Full paper including results/limits reviewed. September 25 v1; authors identify IROS 2026. Official OMRON announcement returned 403 on this read; no bypass. Project links paper/poster/video, no verified implementation payload. Hardware includes one 3x3 PapillArray, wrist F/T, a passive compliant wrist and HTC VIVE gripper-pose tracking; not a tactile-only system.

Offline torque-peak segmentation uses full demonstrations and a subsequent stability heuristic, with end fallback; 80–98% heuristic termination is not boundary-label accuracy. Bidirectional retrieval encoder includes expert-action tokens offline; runtime policy excludes expert future actions. FastDTW aligns phases, retrieves 20 segments, trains each independently with padding masks, preserves complete target trajectories. Do not describe runtime retrieval/chaining or a causal torque-peak detector.

Correct existing all-methods-four-demos wording: BC-Prior uses only 122 prior demos; target-only uses four target demos; retrieval methods use four target demos plus retrieved prior experience. Even shapes absent from the prior have four target examples, so not zero-shot. 77/100 aggregate is full insertion within 60 seconds, 20 trials per five geometries; not best on every shape. Strongest retrieval baseline 64/100, target-only 50/100. OOD 47/100 uses +/-2 cm starts. Short demonstration durations are not policy timing benchmarks. Failures include protective stops, timeout and workspace drift; no recovery or uncertainty guarantee.
